# Support

## Where to get help

- **Bug reports and feature requests:** open a GitHub issue
  using the bug report or feature request template.
- **Usage questions:** open a GitHub issue with the
  question label or start a discussion if discussions are
  enabled for the repository.

## What to include in bug reports

- The image you processed (if you can share it)
- The exact steps you took
- The text shown in any error dialog
- Your operating system, Tesseract, and Liblouis versions

## Out of scope

- Visual Braille output is not tactile Braille. Validate the
  tactile SVG against your embosser before production use.
- Mathematical transcription must be reviewed by a qualified
  human transcriber before educational or production use.
- OCR accuracy limitations: this is a prototype; see
  README.md, Important limitations.
