# Security policy

## Supported versions

The project is at version 0.x and only the latest release
on the main branch receives security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by
email to github@mail.hunsakerweb.com.

Do not open a public GitHub issue for security problems.

Include what you can of:

- The type of issue
- Full paths of source files you believe are involved
- Step-by-step instructions to reproduce
- Proof-of-concept or exploit code
- Impact, including how an attacker might exploit it

You should receive a response within a week. Please use
responsible disclosure; give us a reasonable window to fix
the issue before public disclosure.
